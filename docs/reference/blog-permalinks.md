# 블로그 고정 주소

`web/data/blog-permalinks.json`은 공개 주소와 원문 파일 경로의 매핑입니다. 원문의 한글 제목과 폴더 구조는 바꾸지 않습니다. Nuartz 검색·그래프의 식별자도 원문 경로를 유지하고, 링크를 만들 때만 공개 주소로 바꿉니다.

새 글은 기존 영문 파일명을 우선 활용해 짧은 소문자 kebab-case 주소를 배정합니다. `Overview`처럼 맥락이 필요한 이름에는 프로젝트명을 붙이고, 적절한 영문 이름이 없으면 제목과 내용을 보고 정합니다. 공개 주소는 제목 수정 뒤에도 유지합니다. 빌드에서 누락된 매핑, 중복 원문·이전 주소, 예약 경로와 폴더·별칭 충돌을 검사합니다.

파일을 이동할 때는 공개 주소 키를 유지하고 `source`를 수정합니다. 이전 `source`는 `aliases`에 순서대로 보존합니다. 첫 번째 alias는 기존 댓글의 식별자로도 쓰므로 순서를 바꾸지 않습니다. 삭제하거나 비공개로 전환한 글의 주소는 다른 글에 재배정하지 않습니다.

```json
{
  "langgraph-persistence": {
    "source": "AI/LangGraph/persistence",
    "aliases": ["Dev/old-persistence"]
  }
}
```

기존 경로는 새 주소로 308 리다이렉트됩니다. 브라우저가 이를 캐시할 수 있으므로 공개 후에는 주소 키를 고치는 대신 내용을 수정합니다. canonical, Open Graph, 사이트맵, RSS와 내부 탐색 링크는 새 주소를 사용합니다. Giscus는 기존 pathname에서 계산한 검색어를 명시적으로 전달하여 댓글 연결을 유지합니다.
